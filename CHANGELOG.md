# Changelog

## 0.0.1 — 2026-09-28

- Publish the responsive construction record with Overview, Journey, Records and Home views.
- Show owner-confirmed dates and qualified area estimates with their uncertainty and source context.
- Keep financial, labour, material and equipment totals evidence-based; missing records remain unknown.
- Use a compact desktop navigation rail, a viewport-attached sidebar, and a rounded white content panel; provide labelled mobile navigation.
- Build and deploy the React application through GitHub Pages. Pull requests run the production build before merge.
- Keep detailed plans, exact location, worker identities and raw evidence out of the public site.

This release contains no expense, attendance, material, equipment or photograph records. It does not include an admin interface, database, or inferred construction-completion percentage.
